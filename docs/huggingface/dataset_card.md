# FrameLLaMA FrameNet 1.7 Instruction-Tuning Data (ACL 2026)

The English instruction-tuning corpus used to train
[FrameLLaMA-3.1-8B-Instruct-FullFN17](https://huggingface.co/sag-uniroma2/FrameLLaMA-3.1-8B-Instruct-FullFN17)
in the ACL 2026 paper
**[Frame-Semantic Knowledge Injection for Event-Level Inference in LLMs](https://aclanthology.org/2026.acl-short.55/)**
(Shahid Iqbal Rai, Danilo Croce, Roberto Basili).

The corpus turns the whole FrameNet 1.7 inventory (1,221 frames) into more
than 491,000 instruction–response pairs in 40 task families. It covers frame
definitions, frame elements and their semantic types, sense-aware lexical-unit
definitions, frame-to-frame relations and role-annotated examples. The aim is
principle-oriented supervision: teaching the model the semantic constraints
that FrameNet encodes, rather than isolated facts.

- **Code (generator, training, evaluation):** https://github.com/crux82/FrameLLaMA
- **Model:** https://huggingface.co/sag-uniroma2/FrameLLaMA-3.1-8B-Instruct-FullFN17
- **Paper:** https://aclanthology.org/2026.acl-short.55/

These are the exact files used for the published training run.

## Quick start

```python
from datasets import load_dataset

ds = load_dataset("sag-uniroma2/FrameLLaMA-FullFN17-Instructions")
print(ds)
print(ds["train"][0])
```

While the repository is private, log in first (`huggingface-cli login`) with
an account that has access.

Select one kind of supervision:

```python
relations = ds["train"].filter(lambda x: x["Task Family"] in {"Inherit From", "Uses", "Precedes"})
```

## Example

```json
{
  "Instruction": "Provide the most appropriate factual response to the question.",
  "Question": "Can you describe what typically happens in the \"Indicating\" frame? What kind of situation or event does the Indicating frame represent?",
  "Answer": "The \"Indicating\" frame represents a type of situation or event in which specific participants (called frame elements) play meaningful roles. It describes a scenario where \"A Communicator or Medium assigns linguistic meaning to an Unresolved_referent thereby identifying the specific actor or entity which fulfills the answer to this question.\". ...",
  "Task Family": "Frame Definition"
}
```

## Fields

| Field | Type | Description |
|---|---|---|
| `Instruction` | string | A short generic instruction (e.g. "Please answer the question using correct semantic reasoning."). It varies across examples and does not carry task information. |
| `Question` | string | The FrameNet-derived question: open-ended, Yes/No, or multiple choice (options included in the text). |
| `Answer` | string | The expected response: a sentence or paragraph, `Yes`/`No`, or the correct option. |
| `Task Family` | string | The kind of FrameNet knowledge the example comes from (e.g. `Frame Definition`, `Semantic Type`, `Uses`). |

Training uses only `Instruction`, `Question` and `Answer`, in an Alpaca-style
prompt:

```text
Below is an instruction that describes a task, paired with an input that provides further context. 
Write a response that appropriately completes the request.

### Instruction:
{Instruction}

### Input:
{Question}

### Response:
{Answer}
```

`Task Family` is metadata for analysis: for example, to study the
distribution of supervision types or train on a subset.

## Splits

| Split | File | Examples | Use in the paper |
|---|---|---|---|
| train | `train.json` | more than 491K | LoRA fine-tuning |
| test | `test/Opened.json` | 59.4k open-ended | held-out diagnostic set: in-domain FrameNet QA evaluation (zero-shot base model vs. FrameLLaMA) |
| | `test/Closed.json` | 81.7k yes/no | |
| | `test/MCQ.json` | 106.8k multiple choice | |

The `test` split contains 247.9k held-out FrameNet questions generated by
the same pipeline but not used for training. The paper uses it to check
in-domain acquisition of frame knowledge: the base Meta-Llama-3.1-8B-Instruct
model is evaluated zero-shot and compared with the FrameNet-adapted model,
separately for open-ended, yes/no and multiple-choice questions
(`scripts/evaluate_qa.py` in the GitHub repository).

The question type is not a separate field; it can be read from the answer:
`Yes`/`No` for yes/no questions, an option label such as `c) ...` for
multiple choice, and free text otherwise.

```python
def question_type(answer):
    a = answer.strip()
    if a in ("Yes", "No"):
        return "yes/no"
    if len(a) > 1 and a[0].lower() in "abcde" and a[1] == ")":
        return "multiple choice"
    return "open-ended"

yes_no = ds["test"].filter(lambda x: question_type(x["Answer"]) == "yes/no")
```

The downstream benchmarks of the paper, NLI (CONFER and the SNLI diagnostic
subset) and SRL, are separate resources, distributed in the GitHub
repository under `evaluation/splits/`.

The number of examples per split, question type and Task Family can be
computed with `python tools/dataset_stats.py train.json test/*.json` (in the
GitHub repository).

## How the data were generated

The generator is released in the GitHub repository (`scripts/generate_dataset.py`,
`src/framellama/`). For every FrameNet 1.7 frame it proceeds as follows.

1. **Extraction.** It reads, through NLTK, the frame definition, frame elements
   (FEs) with definitions and semantic types, lexical units (LUs) with POS and
   definitions, annotated example sentences with FE spans, and frame-to-frame
   relations. LUs are kept only if WordNet lists their lemma with the same POS.
2. **Templates.** It fills open-ended, Yes/No and multiple-choice templates for
   the 40 task families below.
3. **Negatives.** "No" answers, wrong MCQ options and "which one is not"
   questions use material from other frames, filtered in two steps:
   - A frame can supply negatives only if it is not directly related to the
     target frame, and the cosine similarity of the two frames' descriptions
     is below 0.50. Each description combines the definition, FEs, semantic
     types, LU definitions and relations, embedded with the sentence-transformers
     model `all-MiniLM-L6-v2`.
   - Each distractor must also have similarity below 0.5 (0.4 for some tasks)
     to the correct answer.
4. **Paraphrased variants.** Each frame is generated twice. For 16 task
   families the second pass uses a second template wording with new
   distractors, and both passes are kept.

The `Instruction` sentence was added when the per-frame output was assembled
into the training files.

### The 40 task families

| Task Family | Tasks (paper numbering) | What is asked |
|---|---|---|
| Frame Definition | T1–T3 | Describe a frame (open); identify a frame from its definition (open); does a definition match a frame (Yes/No) |
| Frame Elements | T4–T10 | List the FEs (open); define an FE in the frame (open); identify a frame from some of its FEs (open); is an FE part of a frame (Yes/No); is an FE definition correct (Yes/No); which role contributes to the situation (MCQ); which role is not involved (MCQ) |
| Semantic Type | T11–T13 | Semantic type of an FE (open, Yes/No, MCQ) |
| Lexical Units | T14–T17, T20 | Which LUs evoke a frame (open); role of an LU in the frame (open); does an LU with this POS evoke the frame (Yes/No); does the LU definition match the frame (Yes/No); which LUs trigger the frame (MCQ) |
| Lexical Unit Polysemy | T18–T19 | Frames evoked by the different senses of an LU (open, Yes/No) |
| Frame Elements Examples | T21–T22 | Write an example sentence for an FE (open); is a span the given FE in an annotated sentence (Yes/No) |
| Inherit From | T23–T25 | Parent frame (open), inheritance link (Yes/No), child of a parent (MCQ) |
| Perspective On | T26–T28 | Frame giving another perspective on the same event (open, Yes/No, MCQ) |
| Uses | T29–T31 | Frame whose structure is used (open, Yes/No, MCQ) |
| SubFrame of | T32–T33 | Component sub-event (open, Yes/No) |
| Precedes | T34–T35 | Temporal ordering of frames (open, Yes/No) |
| Is Causative of | T36, T37, T40 | Resulting state of a causative frame (open, Yes/No, MCQ) |
| Is Inchoative of | T38–T39 | Resulting state of an inchoative frame (open, Yes/No) |

The exact mapping from generator task to paper number is in
`src/framellama/task_families.py` in the GitHub repository. The paper's Table 7
groups T40 under Inchoative; in the generator, that MCQ task is built from the
Is_Causative_of relation. `Task Family` takes the value `Inherit from` (lower-case
"from") for T25, as written by the generator.

## Training configuration

| | |
|---|---|
| Base model | Meta-Llama-3.1-8B-Instruct (Unsloth 4-bit build) |
| Adaptation | LoRA, r = 8, α = 16, dropout 0.1, all attention and MLP projections |
| Optimisation | AdamW 8-bit, learning rate 5e-6, linear schedule, 300 warm-up steps, effective batch size 32, fp16 |
| Length | max. 2,048 tokens, 10 epochs, no validation set |
| Seed | 3407 |

The full configuration is in `configs/acl2026.yaml` in the GitHub repository.
The training script reads `train.json` from this repository directly:

```bash
python scripts/train.py --config configs/acl2026.yaml
# default training data: hf://datasets/sag-uniroma2/FrameLLaMA-FullFN17-Instructions/train.json
```

## Provenance

- **Source:** FrameNet 1.7 (NLTK `framenet_v17` package), all 1,221 frames.
- **Generator:** the research script `tools/original/framenet_dataset_generator.py` in the
  GitHub repository. The reorganised generator in `src/framellama/`
  produces byte-identical output to it for the same frames and seed.
- **Random seed:** the released corpus was generated without a fixed seed.
  Running the generator again gives a corpus built the same way, but with
  different random choices of distractors and option order. Use these files,
  not a regeneration, to reproduce the paper.
- **Related dataset:** [FrameLLaMA-Multilingual-Instructions](https://huggingface.co/datasets/sag-uniroma2/FrameLLaMA-Multilingual-Instructions)
  is a separate corpus (English, Italian, Urdu) produced with a different
  generation procedure and training configuration. Its English portion is not
  the same data as this corpus.

## Limitations

- The data are template-generated: questions and answers follow a limited set
  of formulations, and answers can be verbose or repetitive.
- Coverage is limited to English and to the frames, FEs and LUs of FrameNet 1.7.
- Negatives are filtered automatically by embedding similarity. A small number
  of distractors may still be partially correct.
- The `Instruction` sentences are generic and carry no task information.
